# 🔓 Facebook Forgot Password Tool (SMS Only)

## 📌 Features
- ✅ Automatically send forgot password SMS to phone numbers
- ✅ Load numbers from `.txt` files in a folder
- ✅ Device approval system (admin controlled)
- ✅ Proxy support
- ✅ Multi-threaded for fast processing
- ✅ Report generation
